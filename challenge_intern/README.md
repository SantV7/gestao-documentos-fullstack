Sistema de Gestão de Documentos - Processo Seletivo (Estagiário Full Stack)

Aplicação web desenvolvida para o teste técnico de seleção para a vaga de Estagiário Desenvolvedor Full Stack da Resende Mori Hutchison Advogados Associados.

O sistema permite o upload de arquivos (PDF, JPG e PNG), listagem com histórico de uploads, download/visualização de documentos e gerenciamento de comentários associados a cada arquivo.


🛠️ Tecnologias Utilizadas

Front-end

React + TypeScript – Construção de interface reativa e tipada.

CSS Modules – Estilização escopada e modularizada.

React Router DOM – Navegação SPA e roteamento interno.

React Icons – Conjunto de ícones para melhor visualização na UI.

// ===================================================================


Back-end

Node.js + TypeScript – Plataforma de execução e tipagem estática no servidor.

Express.js – Framework web para criação da API REST.

Multer – Middleware para processamento e upload de arquivos.

// ===================================================================


Banco de Dados & ORM

PostgreSQL – Banco de dados relacional robusto.

Prisma ORM – Modelagem de dados, migrações e consultas tipadas.
